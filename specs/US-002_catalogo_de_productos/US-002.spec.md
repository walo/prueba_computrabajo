## 1. Contratos de Datos y API (Interface Definition)

Siguiendo la **Regla 7 de Redarbor** (*pasar Objetos y no Propiedades como parámetros*), todos los comandos, consultas, métodos de dominio y servicios reciben objetos fuertemente tipados. Cada clase, `record`, `enum` o `interface` reside en su propio archivo (Regla 6).

## 2. Diseño de Backend (.NET 10 Onion Architecture & SQL Server 2022)

- **Reglas de Clean Code Redarbor Obligatorias:**
  - Código y comentarios 100% en inglés (mensajes devueltos al usuario final en español cuando aplique).
  - Cero líneas en blanco dentro de métodos/funciones excepto 1 línea antes de `return`.
  - Métodos de máximo `25` líneas y máximo `1` nivel de anidación de ciclos/condicionales.
  - Exactamente 1 tipo público (`class` / `record` / `interface` / `enum`) por archivo `.cs`.
  - Pasar objetos (`ProductCreationData`, `ProductUpdateData`, `ProductFilter`) en lugar de listas de propiedades escalares.

### A. Dominio (`src/backend/src/Core/Domain`)
- **Entidad `Product : AggregateRoot<Guid>` (`Entities/Product.cs`):**
  - Propiedades:
    - `Id` (`Guid`)
    - `Sku` (`string`, requerido, normalizado `Trim().ToUpperInvariant()`, longitud `2`–`30`, patrón `[A-Z0-9-]+`)
    - `Name` (`string`, requerido, `Trim()`, longitud `2`–`150`)
    - `Description` (`string?`, opcional, longitud máx `500`)
    - `CategoryId` (`Guid`, requerido, referencia lógica a `Category` sin `FOREIGN KEY`)
    - `Price` (`decimal`, `>= 0`)
    - `Stock` (`int`, `>= 0`, establecido al crear con `InitialStock`; inmutable en `Update`)
    - `MinStock` (`int`, `>= 0`)
    - `IsActive` (`bool`, `true` al crear)
    - `CreatedAtUtc` (`DateTime`)
    - `UpdatedAtUtc` (`DateTime?`)
  - Métodos públicos:
    - `public static Product Create(ProductCreationData data)`
    - `public void Update(ProductUpdateData data)`
    - `public void AdjustStock(int newStock)` (validando `newStock >= 0`, reservado para `US-003`)
    - `public bool IsLowStock() => Stock <= MinStock;`
- **ValueObjects / Parameter Objects (`ValueObjects/`):**
  - `ProductCreationData.cs`: `public sealed record ProductCreationData(string Sku, string Name, string? Description, Guid CategoryId, decimal Price, int InitialStock, int MinStock);`
  - `ProductUpdateData.cs`: `public sealed record ProductUpdateData(string Sku, string Name, string? Description, Guid CategoryId, decimal Price, int MinStock, bool IsActive);`
  - `ProductFilter.cs`: `public sealed record ProductFilter(int Page = 1, int PageSize = 10, string? Search = null, Guid? CategoryId = null, bool? IsActive = null, bool? LowStockOnly = null);`
- **Eventos de Dominio (`Events/`):**
  - `ProductCreatedDomainEvent.cs`
  - `ProductUpdatedDomainEvent.cs`
  - `ProductDeletedDomainEvent.cs`
- **Permisos PBAC (`Constants/Permissions.cs`):**
  - Verificar permanencia de `Permissions.Products.{Read, Create, Update, Delete}` ya registrados en `Permissions.GetAll()` y sembrados automáticamente en `InitialDataSeeder.cs` (`ADMIN` recibe todos; `USER` recibe `Products.Read`).

### B. Aplicación (`src/backend/src/Core/Application`)
- **Interfaces (`Common/Interfaces/`):**
  - `IProductRepository.cs`:
    - `Task<Product?> GetByIdAsync(Guid id, CancellationToken ct = default);`
    - `Task<Product?> GetBySkuAsync(string sku, CancellationToken ct = default);`
    - `Task<bool> HasInventoryMovementsAsync(Guid productId, CancellationToken ct = default);`
    - `Task AddAsync(Product product, CancellationToken ct = default);`
    - `Task UpdateAsync(Product product, CancellationToken ct = default);`
    - `Task DeleteAsync(Product product, CancellationToken ct = default);`
  - `IProductFinder.cs`:
    - `Task<PagedProductsResponse> GetPagedAsync(ProductFilter filter, CancellationToken ct = default);`
    - `Task<ProductResponse?> GetByIdAsync(Guid id, CancellationToken ct = default);`
- **Feature Slice `Features/Products/`:**
  - `Commands/CreateProduct/` (`CreateProductCommand`, `CreateProductCommandHandler`, `CreateProductCommandValidator`)
    - Valida existencia de `Category` vía `ICategoryRepository.GetByIdAsync(categoryId, ct)` (`404 Product.CategoryNotFound`), estado activo (`409 Product.CategoryInactive`) y unicidad de `Sku` (`409 Product.DuplicateSku`).
  - `Commands/UpdateProduct/` (`UpdateProductCommand`, `UpdateProductCommandHandler`, `UpdateProductCommandValidator`)
    - Valida existencia de `Product` (`404 Product.NotFound`), existencia y estado activo de `Category` (`404`/`409`) y unicidad de `Sku` excluyendo el propio `Id` (`409 Product.DuplicateSku`). Preserva el `Stock` actual sin sobrescribirlo.
  - `Commands/DeleteProduct/` (`DeleteProductCommand`, `DeleteProductCommandHandler`, `DeleteProductCommandValidator`)
    - Valida existencia de `Product` (`404 Product.NotFound`). Rechaza si `product.Stock > 0` o `await productRepository.HasInventoryMovementsAsync(id, ct)` (`409 Product.CannotDeleteWithStockOrMovements`).
  - `Queries/GetProducts/` (`GetProductsQuery`, `GetProductsQueryHandler`, `GetProductsQueryValidator`)
  - `Queries/GetProductById/` (`GetProductByIdQuery`, `GetProductByIdQueryHandler`, `GetProductByIdQueryValidator`)
  - `DTOs/` (`CreateProductRequest`, `UpdateProductRequest`, `ProductResponse`, `PagedProductsResponse`)

### C. Infraestructura y Persistencia SQL Server (`src/backend/src/Infrastructure/Persistence`)
- **`AppDbContext.cs`:** `public DbSet<Product> Products => Set<Product>();`
- **`Configurations/ProductConfiguration.cs`:**
  - Tabla: `Products`, clave primaria `Id` con `.ValueGeneratedNever()`.
  - Columnas: `Sku` (`nvarchar(30)` required), `Name` (`nvarchar(150)` required), `Description` (`nvarchar(500)`), `CategoryId` (`uniqueidentifier` required), `Price` (`decimal(18,2)` required), `Stock` (`int` required), `MinStock` (`int` required), `IsActive` (`bit` required), `CreatedAtUtc` (`datetime2` required), `UpdatedAtUtc` (`datetime2`).
  - Índices: `IX_Products_Sku` (`IsUnique()`), `IX_Products_CategoryId` (no único).
  - **Prohibido usar `.HasForeignKey()` o `FOREIGN KEY`**.
- **`Finders/ProductFinder.cs`:**
  - Lectura 100% con **EF Core `.AsNoTracking()`** y `Join` entre `dbContext.Products` y `dbContext.Categories` por `product.CategoryId == category.Id` para proyectar `CategoryCode` y `CategoryName`.
  - Filtros soportados: `CategoryId`, `IsActive`, `LowStockOnly` (`product.Stock <= product.MinStock`), `Search` (sobre `Sku` o `Name`), ordenamiento `OrderBy(product => product.Name)` y paginación `Skip`/`Take`.
- **`Repositories/ProductRepository.cs`:**
  - `INSERT`, `UPDATE` y `DELETE` parametrizados con **Dapper** usando `IDbConnectionFactory` en bases relacionales (con respaldo EF Core InMemory cuando `!dbContext.Database.IsRelational()`).
  - `HasInventoryMovementsAsync` usando el patrón seguro en 2 pasos:
    1. `SELECT CASE WHEN OBJECT_ID(N'dbo.InventoryMovements', N'U') IS NOT NULL THEN CAST(1 AS BIT) ELSE CAST(0 AS BIT) END`
    2. Solo si la tabla existe: `SELECT CASE WHEN EXISTS (SELECT 1 FROM dbo.InventoryMovements WHERE ProductId = @ProductId) THEN CAST(1 AS BIT) ELSE CAST(0 AS BIT) END`.
- **Migración EF Core `AddProductsCatalog`:** Verifica `0` ocurrencias de `ForeignKey` y activa automáticamente `CategoryRepository.HasAssociatedProductsAsync` en SQL Server.

### D. Presentación (`src/backend/src/Presentation/Web.API`)
- `Controllers/ProductsController.cs`: hereda `ApiController`, ruta `api/v1/products`, decorado con `[HasPermission(Permissions.Products.*)]`.

## 3. Diseño de Frontend (Angular 22+ Zoneless & `@accionadev/ui-kit`)

- **Componentes `@accionadev/ui-kit` a Reutilizar (verificados en `../ui-design-system/ui-manifest.json`):**
  - Barra superior y filtros: `<ad-card>`, `<ad-search-box>`, `<ad-select>` (Categoría y Estado), `<ad-switch>` (`Solo stock bajo`), `<ad-button>`, `<ad-icon>`.
  - Grilla y alertas: `<ad-table>`, `ng-template[adTableCell]`, `<ad-table-actions>`, `<ad-badge>` (`success`/`neutral` para estado; `danger`/`warning`/`success` para nivel de stock), `<ad-empty-state>`.
  - Modal Crear/Editar: `<ad-modal>`, `<ad-input>` (`text`, `number`, `icon="dollar"` para Precio), `<ad-select>` (Categorías activas cargadas vía `CategoriesService`), `<ad-textarea>`, `<ad-switch>` (`IsActive` visible solo al editar), `<ad-alert>`.
  - Confirmación de borrado: `AdConfirmService` consumiendo el `<ad-confirm-dialog />` global montado en `app.html`.
- **Arquitectura Modular (`src/frontend/src/app/`):**
  - **Modelos (`features/products/models/`):** `product.model.ts`, `product-filter.model.ts`, `create-product-request.model.ts`, `update-product-request.model.ts`, `product-update-command.model.ts`, `paged-products-response.model.ts`.
  - **Servicio HTTP (`features/products/services/products.service.ts`):** Consume `API_PATHS.PRODUCTS.BASE` pasando objetos (`ProductFilter`, `CreateProductRequest`, `ProductUpdateCommand`).
  - **Smart Component (`features/products/pages/product-list.component.ts` + `.html`):**
    - `ChangeDetectionStrategy.OnPush`, Signals (`products`, `activeCategories`, `totalCount`, `page`, `pageSize`, `search`, `categoryFilter`, `statusFilter`, `lowStockOnly`, `isLoading`, `isModalOpen`, `isSaving`, `editingProduct`, `modalError`).
    - Al abrir el modal en modo **Crear**, muestra `initialStock` (`min = 0`); al abrir en modo **Editar**, oculta `initialStock` y muestra `isActive`.
    - Acciones condicionadas por `*ngxPermissionsOnly="[permissions.PRODUCTS.CREATE / UPDATE / DELETE]"`.
  - **Navegación y Seguridad:**
    - `features.routes.ts`: ruta `products` con `permissionGuard` (`PERMISSIONS.PRODUCTS.READ`).
    - `ShellComponent`: `pageTitle()` retorna `'Catálogo de Productos'` para `/products` y `navItems()` agrega `{ id: 'products', label: 'Productos', route: '/products', icon: 'package' }` condicionado por `PERMISSIONS.PRODUCTS.READ`.
    - `DashboardComponent`: envolver la tarjeta existente de Productos en `<a *ngxPermissionsOnly="[permissions.PRODUCTS.READ]" routerLink="/products" ...>`.

Agregar estas claves en `src/frontend/src/app/core/config/error-messages.json`:

| Código de Dominio (`code`) | HTTP Status | Mensaje en UI para el Usuario |
| :--- | :--- | :--- |
| `Product.NotFound` | `404` | "El producto solicitado no existe o fue eliminado." |
| `Product.DuplicateSku` | `409` | "Ya existe un producto registrado con el SKU ingresado." |
| `Product.CategoryNotFound` | `404` | "La categoría seleccionada no existe." |
| `Product.CategoryInactive` | `409` | "No se puede asociar el producto a una categoría inactiva." |
| `Product.CannotDeleteWithStockOrMovements` | `409` | "No se puede eliminar un producto con stock mayor a cero o movimientos históricos. Considere inactivarlo." |
| `Product.InvalidSku` | `400` | "El SKU debe tener entre 2 y 30 caracteres alfanuméricos o guiones." |
| `Product.InvalidName` | `400` | "El nombre del producto debe tener entre 2 y 150 caracteres." |
| `Validation.Error` | `400` | "Verifica los campos obligatorios y los valores numéricos permitidos." |
