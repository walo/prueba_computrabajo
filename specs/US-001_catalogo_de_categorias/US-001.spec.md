## 1. Contratos de Datos y API (Interface Definition)

Siguiendo la **Regla 7 de Redarbor** (*pasar Objetos y no Propiedades como parámetros*), todos los comandos, consultas y servicios reciben objetos fuertemente tipados. Cada clase, `record`, `enum` o `interface` reside en su propio archivo (Regla 6).

### A. DTOs de Entrada (Request & Filter Models)
```typescript
export interface CreateCategoryRequest {
  code: string;
  name: string;
  description: string | null;
}

export interface UpdateCategoryRequest {
  code: string;
  name: string;
  description: string | null;
  isActive: boolean;
}

export interface CategoryFilter {
  page: number;
  pageSize: number;
  search?: string;
  isActive?: boolean | null;
}
```

```csharp
public sealed record CreateCategoryRequest(
    string Code,
    string Name,
    string? Description);

public sealed record UpdateCategoryRequest(
    string Code,
    string Name,
    string? Description,
    bool IsActive);

public sealed record CategoryFilter(
    int Page = 1,
    int PageSize = 10,
    string? Search = null,
    bool? IsActive = null);

public sealed record CreateCategoryCommand(CreateCategoryRequest Payload)
    : IRequest<ErrorOr<CategoryResponse>>;

public sealed record UpdateCategoryCommand(Guid Id, UpdateCategoryRequest Payload)
    : IRequest<ErrorOr<CategoryResponse>>;

public sealed record DeleteCategoryCommand(Guid Id)
    : IRequest<ErrorOr<Deleted>>;

public sealed record GetCategoriesQuery(CategoryFilter Filter)
    : IRequest<ErrorOr<PagedCategoriesResponse>>;

public sealed record GetCategoryByIdQuery(Guid Id)
    : IRequest<ErrorOr<CategoryResponse>>;
```

### B. DTOs de Salida (Response Models)

export interface CategoryDto {

## 2. Diseño de Backend (.NET 10 Onion Architecture & SQL Server 2022)

- **Reglas de Clean Code Redarbor Obligatorias:**
  - Código y comentarios 100% en inglés (mensajes devueltos al usuario final en español cuando aplique).
  - Cero líneas en blanco dentro de métodos/funciones excepto 1 línea antes de `return`.
  - Métodos de máximo `25` líneas y máximo `1` nivel de anidación de ciclos/condicionales.
  - Exactamente 1 tipo público (`class` / `record` / `interface` / `enum`) por archivo `.cs`.
  - Pasar objetos (`CategoryCreationData`, `CategoryUpdateData`, `CategoryUniquenessFilter`, `CategoryFilter`) en lugar de listas de propiedades escalares.
- **Dominio (`Core/Domain`):**
  - Entidad `Category : AggregateRoot<Guid>`:
    - Propiedades: `Id`, `Code` (normalizado `Trim().ToLowerInvariant()`, max `30`), `Name` (normalizado `Trim()`, max `100`), `Description` (opcional, max `500`), `IsActive` (default `true`), `CreatedAtUtc`, `UpdatedAtUtc`.
    - Métodos fábrica/mutación con objeto: `Category.Create(CategoryCreationData data)` y `category.Update(CategoryUpdateData data)`.
  - Objetos de parámetro en `Core/Domain/Entities/`: `CategoryCreationData.cs`, `CategoryUpdateData.cs`, `CategoryUniquenessFilter.cs`, `CategoryFilter.cs`.
  - Eventos de dominio en `Core/Domain/Events/`: `CategoryCreatedDomainEvent.cs`, `CategoryUpdatedDomainEvent.cs`, `CategoryDeletedDomainEvent.cs`.
  - Constantes de permiso en `Domain/Constants/Permissions.cs`: ya definidos `Permissions.Categories.{Read, Create, Update, Delete}`.
- **Aplicación (`Core/Application`):**
  - Interfaces en `Application/Common/Interfaces/`:
    - `ICategoryRepository`: `GetByIdAsync(Guid id, CancellationToken ct)`, `GetUniquenessConflictAsync(CategoryUniquenessFilter filter, CancellationToken ct)`, `HasAssociatedProductsAsync(Guid categoryId, CancellationToken ct)`, `AddAsync(Category entity, CancellationToken ct)`, `UpdateAsync(Category entity, CancellationToken ct)`, `DeleteAsync(Category entity, CancellationToken ct)`.
    - `ICategoryFinder`: `GetPagedAsync(CategoryFilter filter, CancellationToken ct)`, `GetByIdAsync(Guid id, CancellationToken ct)`.
  - Feature slice `Application/Features/Categories/`:
    - `Commands/CreateCategory/` (`CreateCategoryCommand`, `CreateCategoryCommandHandler`, `CreateCategoryCommandValidator`)
    - `Commands/UpdateCategory/` (`UpdateCategoryCommand`, `UpdateCategoryCommandHandler`, `UpdateCategoryCommandValidator`)
    - `Commands/DeleteCategory/` (`DeleteCategoryCommand`, `DeleteCategoryCommandHandler`)
    - `Queries/GetCategories/` (`GetCategoriesQuery`, `GetCategoriesQueryHandler`, `GetCategoriesQueryValidator`)
    - `Queries/GetCategoryById/` (`GetCategoryByIdQuery`, `GetCategoryByIdQueryHandler`)
    - `DTOs/` (`CreateCategoryRequest`, `UpdateCategoryRequest`, `CategoryResponse`, `PagedCategoriesResponse`)
- **Persistencia (`Infrastructure/Persistence`):**
  - `AppDbContext`: agregar `public DbSet<Category> Categories => Set<Category>();`.
  - `Configurations/CategoryConfiguration.cs`: tabla `Categories`, `.ValueGeneratedNever()` en `Id`, índices únicos en `Code` y `Name` (colación case-insensitive o columna normalizada), **cero `.HasForeignKey()`**.
  - `Finders/CategoryFinder.cs`: lecturas 100% con **EF Core `.AsNoTracking()`** (`GetPagedAsync`, `GetByIdAsync`).
  - `Repositories/CategoryRepository.cs`: escrituras SQL parametrizadas con **Dapper** sobre `IDbConnectionFactory` (`INSERT`, `UPDATE`, `DELETE`), verificación segura de productos asociados (`CASE WHEN OBJECT_ID(N'dbo.Products', N'U') IS NOT NULL AND EXISTS (SELECT 1 FROM dbo.Products WHERE CategoryId = @CategoryId) ...`), y respaldo InMemory cuando `!dbContext.Database.IsRelational()`.
  - Migración EF Core: `AddCategoriesCatalog` aplicada sobre `redarbor-sqlserver`, verificando `0` `FOREIGN KEY` generadas.
- **Presentación (`Presentation/Web.API`):**
  - `Controllers/CategoriesController.cs`: hereda `ApiController`, decorado con `[HasPermission(Permissions.Categories.*)]`, delega a `ISender`.
- **Pruebas Automatizadas Backend (`tests/`):**
  - `Tests.UnitTests`: dominio (`CategoryTests`), validadores (`CreateCategoryCommandValidatorTests`, `UpdateCategoryCommandValidatorTests`, `GetCategoriesQueryValidatorTests`), handlers (`CreateCategoryCommandHandlerTests`, `UpdateCategoryCommandHandlerTests`, `DeleteCategoryCommandHandlerTests`, `GetCategoriesQueryHandlerTests`).
  - `Tests.IntegrationTests`: `CategoriesIntegrationTests` validando PBAC (`401` / `403`), CRUD completo, paginación/filtros, conflicto por código/nombre duplicado y Swagger.

## 3. Diseño de Frontend (Angular 22+ Zoneless & `@accionadev/ui-kit`)

- **Componentes `@accionadev/ui-kit` a Reutilizar (según `../ui-design-system/ui-manifest.json`):**
  - Tabla y estado vacío: `<ad-table>`, `ng-template[adTableCell]`, `<ad-table-actions>`, `<ad-badge>`.
  - Barra de filtros y cabecera: `<ad-card>`, `<ad-search-box>`, `<ad-select>`, `<ad-button>`, `<ad-icon>`.
  - Modal de formulario: `<ad-modal>`, `<ad-input>`, `<ad-textarea>`, `<ad-switch>`, `<ad-alert>`.
  - Confirmación de borrado: `<ad-confirm-dialog />` montado en `app.html` + `AdConfirmService`.
  - Cero HTML nativo improvisado (`<button>`, `<input>`, `<select>`, `<table>`, `<svg>` manuales) y cero colores `#hex`.
- **Arquitectura Modular (`src/frontend/src/app/`):**
  - **Modelos (`features/categories/models/`):** `category.model.ts`, `category-filter.model.ts`, `create-category-request.model.ts`, `update-category-request.model.ts`, `paged-categories-response.model.ts`.
  - **Servicio HTTP (`features/categories/services/categories.service.ts`):** Consume `API_PATHS.CATEGORIES.BASE` pasando objetos (`CategoryFilter`, `CreateCategoryRequest`, `UpdateCategoryRequest`).
  - **Smart Component (`features/categories/components/categories-page.component.ts`):**
    - `ChangeDetectionStrategy.OnPush`, Signals (`categories`, `totalCount`, `page`, `pageSize`, `search`, `statusFilter`, `isLoading`, `isModalOpen`, `isSaving`, `editingCategory`, `modalError`).
    - Formularios reactivos (`FormBuilder`) para crear/editar categoría con validaciones sincronizadas.
    - Botones de creación/edición/eliminación protegidos por `*ngxPermissionsOnly` (`PERMISSIONS.CATEGORIES.*`).
  - **Navegación y Seguridad:**
    - `FEATURES_ROUTES`: ruta `categories` protegida por `permissionGuard` con `data: { permissions: [PERMISSIONS.CATEGORIES.READ] }`.
    - `ShellComponent.navItems()`: ítem `{ id: 'categories', label: 'Categorías', route: '/categories', icon: 'tag' }` visible solo cuando el usuario posee `PERMISSIONS.CATEGORIES.READ`.
    - Enlace rápido desde `DashboardComponent` en la tarjeta de Categorías.
  - **Pruebas Jest Zoneless:** `categories.service.spec.ts` (`HttpTestingController`) y `categories-page.component.spec.ts` (render de tabla, modal crear/editar, confirmación de borrado, paginación y `*ngxPermissionsOnly`).

## 5. Catálogo de Errores Semánticos (UI Error Translation)

Agregar estas claves en `src/frontend/src/app/core/config/error-messages.json` y utilizarlas en `CategoriesPageComponent`:

| Código de Dominio (`code`) | HTTP Status | Mensaje en UI para el Usuario |
| :--- | :--- | :--- |
| `Category.NotFound` | `404` | "La categoría solicitada no existe o fue eliminada." |
| `Category.DuplicateCode` | `409` | "Ya existe una categoría registrada con ese código." |
| `Category.DuplicateName` | `409` | "Ya existe una categoría registrada con ese nombre." |
| `Category.HasAssociatedProducts` | `409` | "No se puede eliminar la categoría porque tiene productos asociados. Puedes editarla e inactivarla en su lugar." |
| `Validation.Error` | `400` | "Verifica los campos obligatorios y las longitudes permitidas." |
| `Auth.Forbidden` | `403` | "No tienes permisos para realizar esta acción sobre Categorías." |
